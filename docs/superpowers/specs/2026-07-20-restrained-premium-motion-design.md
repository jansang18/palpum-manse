# 절제형 프리미엄 모션 디자인 명세

## 목표

신의 음성 만세력의 고급스럽고 신비로운 다크 디자인을 유지하면서, 상태가 순간적으로 바뀌어 보이는 네 지점에만 짧고 기능적인 모션을 추가한다. 원국과 운 흐름처럼 사용자가 읽고 비교하는 고밀도 정보는 움직이지 않는다.

## 디자인 원칙

- 모션은 피드백, 공간적 일관성, 상태 표시를 위해서만 사용한다.
- 한 번의 전환은 100~240ms 안에 끝낸다.
- 기본 곡선은 기존 UI에서 사용하는 `cubic-bezier(.2,.7,.2,1)`을 재사용한다.
- `transform`과 `opacity`만 애니메이션하여 모바일 성능과 정사각형 레이아웃을 보존한다.
- 애니메이션 중에도 클릭과 스크롤을 불필요하게 차단하지 않는다.
- `prefers-reduced-motion: reduce`에서는 이동 거리를 0~4px로 줄이고 100~120ms의 짧은 투명도 전환만 사용한다.

## 적용 범위

### 1. 모달 열기와 닫기

- 대상: 명반 저장, 비슷한 사주, 궁합 선택, 궁합 새 입력, 인물 검색, 앱 정보 모달.
- 열기: 배경은 `opacity: 0 → 1`, 시트는 `translateY(100%) → 0`, 240ms.
- 닫기: 배경은 `opacity: 1 → 0`, 시트는 `translateY(0) → 100%`, 220ms.
- 닫기 중 중복 입력을 막고, 전환 종료 후에만 활성 클래스를 제거한다.
- Android 뒤로가기, 취소 버튼, 배경 탭 모두 동일한 닫기 함수를 사용한다.
- 데스크톱 중앙 모달은 `translateY(8px)`와 `opacity`만 사용하고 화면 아래까지 이동하지 않는다.

### 2. 저장 완료 토스트

- 기존 `alert('저장되었습니다')`를 비차단식 토스트로 교체한다.
- 화면 하단 고정 버튼 위에 표시하며, `translateY(12px)`와 `opacity: 0`에서 180ms 동안 등장한다.
- 1.8초 유지 후 140ms 동안 사라진다.
- 같은 메시지가 연속 호출되면 기존 타이머를 취소하고 하나의 토스트만 재사용한다.
- `aria-live="polite"`와 `role="status"`를 사용한다.
- 저장 실패 처리 방식과 저장 데이터 구조는 변경하지 않는다.

### 3. 달력 월 이동

- 이전 달은 현재 달력이 오른쪽으로 8px, 새 달력이 왼쪽에서 8px 이동한다.
- 다음 달은 현재 달력이 왼쪽으로 8px, 새 달력이 오른쪽에서 8px 이동한다.
- 퇴장은 90ms, DOM 갱신 후 진입은 160ms이다.
- 날짜 선택으로 같은 달력을 다시 그릴 때는 월 이동 모션을 실행하지 않는다.
- 전환 중 이전·다음 버튼의 연속 입력은 마지막 요청만 반영하여 월이 중복 변경되지 않게 한다.
- 날짜 칸 개별 스태거나 한자 애니메이션은 적용하지 않는다.

### 4. 궁합 슬롯 채움

- 비어 있던 궁합 슬롯이 인물 정보로 바뀔 때 해당 슬롯 하나만 등장시킨다.
- 시작 상태는 `opacity: 0`, `scale(.97)`이며 180ms 동안 정상 상태로 전환한다.
- 이미 채워진 슬롯 재렌더링과 궁합 결과 화면에는 반복 적용하지 않는다.
- 슬롯 내용과 계산 로직은 변경하지 않는다.

## 제외 범위

- 메인 로고의 반복 광채, 회전, 부유 효과.
- 원국, 대운, 세운, 월운, 일운 한자의 이동 또는 스태거.
- 풀이 점수 막대의 추가 연출.
- 탭 전환 애니메이션 확대.
- 달력 날짜 42개의 개별 등장 효과.

## 구현 구조

- CSS 모션 토큰과 상태 클래스는 `luxury.css`에 추가한다.
- 모달 열기/닫기, 토스트, 달력 전환, 궁합 슬롯 진입을 위한 작은 함수는 `index.html`의 기존 스크립트 영역에 둔다.
- 기존 `classList.add('active')`와 `classList.remove('active')` 호출은 공통 모달 함수로 연결한다.
- Android 뒤로가기 처리는 `nav.js`에서 공통 모달 닫기 함수를 우선 호출하되, 함수가 없을 때 기존 방식으로 동작하도록 한다.
- 웹용 `app/web`과 APK용 `app/www`에 동일한 동작을 유지한다.

## 오류와 경계 조건

- 빠르게 모달을 다시 열면 이전 닫기 타이머를 취소한다.
- `transitionend`가 발생하지 않는 환경을 위해 시간 기반 안전 종료를 함께 둔다.
- 저감 모드에서도 상태 변경은 즉시 이해할 수 있어야 한다.
- 달력 전환 중 탭을 벗어나도 숨겨진 화면에 잔여 클래스를 남기지 않는다.
- 토스트는 화면 안전 영역과 하단 버튼을 가리지 않는다.

## 검증 기준

- 테스트는 구현 전에 추가하고 새 동작이 없어서 실패하는 것을 먼저 확인한다.
- 360, 390, 412, 768px에서 가로 넘침이 없어야 한다.
- 원국과 운 흐름 한자 칸은 기존 정사각형 비율을 유지해야 한다.
- 모달은 열기와 닫기 모두 완료 후 올바른 `active` 상태를 가져야 한다.
- 저장 완료 시 시스템 `alert()`가 호출되지 않고 접근 가능한 토스트가 표시되어야 한다.
- 달력 이전·다음 방향이 서로 반대이며, 날짜 선택에는 월 전환 모션이 없어야 한다.
- 궁합에서는 새로 채워진 슬롯 하나에만 진입 클래스가 적용되어야 한다.
- `prefers-reduced-motion` 검사에서 큰 이동과 긴 전환이 제거되어야 한다.
- 일반 웹 소스와 난독화 Android 자산 모두 UI 회귀 검사를 통과해야 한다.
