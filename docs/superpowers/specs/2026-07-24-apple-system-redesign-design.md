# 취명선 만세력 Apple 시스템 리디자인 명세

작성일: 2026-07-24  
대상: `app/www` 원본 UI, `app/web` 웹 배포본, Capacitor Android 빌드

표시 이름: **취명선 만세력**

## 1. 목표

기존의 금색·우주·장식 중심 디자인을 제거하고 Apple 플랫폼 앱처럼 명확하고 차분한 인터페이스로 전면 재설계한다. Apple 상표나 로고를 모방하지 않으며, Apple Human Interface Design의 정보 계층, 여백, 재질, 타이포그래피, 즉각적인 터치 반응을 웹과 Android 환경에 맞게 적용한다.

제품의 감정은 **예쁘고, 귀엽고, 부드럽지만 유치하지 않은 차분함**으로 정한다. 귀여움은 캐릭터나 장식 남용이 아니라 둥근 형태, 파스텔 오행색, 편안한 여백, 짧고 부드러운 반응에서 만든다.

성공 기준:

- 라이트와 다크 테마가 모두 완성된 독립 디자인으로 보인다.
- 금색 계열 색상과 금색 테두리·광택·글로우가 화면에 남지 않는다.
- 화면마다 제목, 핵심 행동, 보조 정보의 우선순위가 즉시 구분된다.
- 천간·지지 한자 블록은 모든 화면에서 동일한 정사각형과 글자 크기 규칙을 따른다.
- 모든 박스의 글자·아이콘은 가로와 세로의 실제 중심에 정렬되고, 같은 행의 기준선과 높이가 일치한다.
- 360, 390, 412, 768px에서 잘림과 비정상적인 가로 스크롤이 없다.
- 기존 만세력 계산, 저장, 공유, 궁합, 달력, 운세 흐름 기능은 유지된다.
- 화면 제목, HTML/PWA 메타데이터, Android 앱 라벨, 공유 카드의 표시 이름은 `취명선 만세력`으로 통일한다.
- 기존 설치 업데이트와 서명 연속성을 위해 Android package ID와 서명 키는 변경하지 않는다.

## 2. 선택한 방향

### A. Apple 시스템 UI 중심

선택된 방향이다.

- 바탕: iOS 계열 grouped background
- 표면: 명확한 단색 카드와 얇은 hairline separator
- 강조: 시스템 블루
- 텍스트: 시스템 폰트와 iOS식 계층
- 모션: 짧고 물리적이며 즉시 중단 가능한 전환
- 브랜드: 단색 로고와 앱 이름만 유지

### 제외한 방향

- Apple 구조와 금색 신비주의를 혼합하는 방식: 사용자가 금색 제거를 요청해 제외한다.
- 유리 효과와 블러를 과도하게 사용하는 방식: 정보 밀도가 높은 명식 화면의 가독성을 해치므로 제외한다.

## 3. 색상 체계

CSS 의미 토큰으로 관리하고 화면별 직접 색상 사용을 최소화한다.

### 라이트

- 배경: `#F2F2F7`
- 1차 표면: `#FFFFFF`
- 2차 표면: `#F7F7FA`
- 1차 텍스트: `#111113`
- 2차 텍스트: `#636366`
- 3차 텍스트: `#8E8E93`
- 구분선: `rgba(60, 60, 67, 0.16)`
- 강조: `#007AFF`
- 눌림 강조: `#0062CC`

### 다크

- 배경: `#000000`
- 1차 표면: `#1C1C1E`
- 2차 표면: `#2C2C2E`
- 1차 텍스트: `#F5F5F7`
- 2차 텍스트: `#AEAEB2`
- 3차 텍스트: `#8E8E93`
- 구분선: `rgba(84, 84, 88, 0.58)`
- 강조: `#0A84FF`
- 눌림 강조: `#409CFF`

오행색은 계산 정보 전달에 필요하므로 Apple식 파스텔 팔레트로 다시 구성한다. 오행색은 한자 블록과 작은 상태 표시에만 쓰고, 카드·버튼·테두리 장식에는 사용하지 않는다.

### 오행 파스텔 팔레트

라이트 테마는 연한 파스텔 표면과 충분히 진한 동계열 글자를 조합하고, 다크 테마는 짙은 색조 표면 위에 밝은 파스텔 글자를 사용한다. 일반 본문은 파스텔로 바꾸지 않아 읽기 대비를 유지한다.

| 오행 | 라이트 표면 | 라이트 글자 | 다크 표면 | 다크 글자 |
| --- | --- | --- | --- | --- |
| 목 | `#DDF6E8` | `#237A4B` | `#143629` | `#7BE0A8` |
| 화 | `#FFE3DF` | `#B84438` | `#41201D` | `#FF9A8F` |
| 토 | `#FFF1C7` | `#7A6200` | `#3A3014` | `#F2D36F` |
| 금 | `#ECEFF4` | `#505B6B` | `#2B3038` | `#C8D0DC` |
| 수 | `#E2E7FF` | `#4054A3` | `#20284A` | `#A7B4FF` |

십신·상태 capsule은 해당 오행색보다 채도를 낮춘 배경과 고대비 글자를 사용한다.

## 4. 타이포그래피

- 기본 글꼴: `-apple-system`, `BlinkMacSystemFont`, `"Apple SD Gothic Neo"`, `"Noto Sans KR"`, sans-serif
- 화면 제목: 28px, 700, `letter-spacing: -0.025em`
- 섹션 제목: 20px, 700, `letter-spacing: -0.018em`
- 카드 제목: 17px, 650
- 본문: 15px, 450, `line-height: 1.55`
- 보조문: 13px, 500
- 캡션: 11px, 600
- 한자: 정사각형 안에서 `clamp()`로 통일하고 동일한 `line-height: 1`

작은 글자는 자간을 지나치게 줄이지 않는다. 16px 미만 입력 필드를 만들지 않아 iOS 브라우저의 자동 확대 문제를 방지한다.

## 5. 화면 구조

### 상단바

- 투명한 고정 헤더 대신 반투명 재질의 sticky navigation bar를 사용한다.
- 스크롤 전에는 배경이 가볍고, 콘텐츠가 아래로 지나갈 때 blur와 분리감이 생긴다.
- 좌측 앱 이름, 우측 테마와 정보 버튼을 유지한다.
- 로고와 텍스트는 라이트에서 검정, 다크에서 흰색 단색으로 표현한다.

### 탭

- 여섯 기능은 현재 정보 구조를 유지한다.
- 상단의 가로형 tab rail을 Apple식 segmented navigation으로 바꾼다.
- 선택 항목은 파란색 글자와 부드러운 capsule 배경으로 표시한다.
- 금색 밑줄과 글로우는 제거한다.
- 작은 화면에서도 한눈에 보이도록 균등 폭을 우선하고, 필요한 경우 글자 크기를 12px까지 유연하게 줄인다.

### 화면 콘텐츠

- 각 탭 상단에 큰 제목과 한 줄 설명을 둔다.
- 관련 입력은 inset grouped card 안에 묶는다.
- 카드 사이 간격은 12px, 화면 가장자리 여백은 16px을 기본으로 한다.
- 테두리는 최소화하고 배경 대비와 얇은 separator로 그룹을 표현한다.

## 6. 컴포넌트

### 입력 폼

- 높이 52px, 반경 12px
- 라이트는 회백색 필드, 다크는 2차 표면
- 포커스 시 파란색 2px ring
- 라벨은 입력 위에 두고 placeholder보다 명확하게 표시
- 성별·양음력은 iOS segmented control 형태

### 주요 버튼

- 높이 54px, 반경 14px
- 시스템 블루 단색
- 장식 별, 그라데이션, 금속 광택 제거
- pointer-down에서 즉시 `scale(0.98)`과 밝기 변화
- 비활성 상태는 회색과 낮은 대비로 명확히 구분
- 아이콘은 둥근 2px 선과 작은 크기로 통일하고, 글자와 8px 간격을 둔다.

### 카드와 목록

- 기본 카드 반경 18px
- 동일 그룹 내부 항목은 개별 카드 대신 separator로 연결
- 그림자는 라이트에서 매우 약하게, 다크에서는 사용하지 않거나 최소화
- 선택 상태는 파란색 테두리보다 연한 파란색 배경과 check 상태를 우선

### 한자 정사각형

- `aspect-ratio: 1 / 1`
- 같은 컨테이너의 모든 칸은 CSS grid의 동일 열 폭 사용
- 내부는 `display: grid; place-items: center`를 기본으로 하고 불필요한 padding을 제거한다.
- 한자는 기하학적 중앙 정렬 후, CJK 글꼴의 시각적 중심 차이를 보정하는 단일 CSS 변수만 사용한다.
- 개별 화면이나 글자마다 별도의 `top`, `margin`, `translateY` 값을 사용하지 않는다.
- 한자와 한글 음 표시는 각각 독립된 고정 행에 배치해 한자가 한글 때문에 위아래로 밀리지 않게 한다.
- 천간·지지·대운·세운·월운·일운에서 동일한 크기 계산식 사용
- 지장간은 밝은/어두운 테마 모두 고대비 capsule로 표시

### 정렬 시스템

- 카드·버튼·입력 필드·탭·운세 칸에 공통 높이와 공통 spacing token을 사용한다.
- 같은 행의 박스는 CSS grid의 `align-items: stretch`로 높이를 맞춘다.
- 박스 안의 단일 라벨은 `display: grid; place-items: center`로 가로·세로 중앙 정렬한다.
- 두 줄 이상의 내용은 전체 블록을 중앙에 두되 텍스트 읽기 방향은 용도에 따라 좌측 정렬한다.
- 아이콘과 글자의 조합은 고정 gap을 사용하고 아이콘 자체의 viewBox 여백까지 고려해 시각 중심을 맞춘다.
- 버튼·탭·한자 칸은 홀수 픽셀의 반쪽 좌표로 흐려지지 않도록 최종 크기와 위치를 정수 픽셀에 가깝게 유지한다.
- 모바일과 태블릿에서 같은 컴포넌트가 서로 다른 임의 보정값을 갖지 않도록 공통 토큰을 사용한다.

### 운세 흐름

- 대운·세운·월운·일운 제목은 중앙 정렬 유지
- 행은 화면 폭을 최대한 쓰되 글자 칸의 정사각형을 깨지 않는다.
- 10개 이상 항목은 `grid-template-columns: repeat(n, minmax(0, 1fr))`
- 선택된 운은 파란색 selection ring과 연한 강조 배경으로 표시
- 하위 흐름은 중첩 카드가 아니라 다음 섹션으로 자연스럽게 이어진다.

### 모달과 시트

- 휴대폰: 하단 sheet
- 넓은 화면: 중앙 dialog
- 배경은 blur + dim
- sheet 상단에 grabber 표시
- 기존 interruptible animation과 포커스 트랩, ESC/뒤로가기 처리를 유지
- 닫기와 열기는 현재 화면 위치에서 시작하며 같은 경로를 역으로 사용

### 알림

- 저장 성공은 하단 toast
- 오류는 관련 입력 바로 아래 inline message
- 파괴적 작업만 확인 dialog 사용

## 7. 모션

- 터치 피드백: 80~100ms
- 탭 선택: 180~220ms
- 화면 전환: 220ms 이내의 opacity/translate
- sheet: 240~300ms, 과한 bounce 없음
- 달력: 기존 방향성 전환 유지
- 궁합 인물이 처음 채워질 때만 0.12 이하의 미세한 spring 감각을 허용한다.
- 반복 장식 애니메이션과 자동 반짝임은 제거
- `prefers-reduced-motion`에서는 이동을 제거하고 짧은 cross-fade만 사용

## 8. 접근성과 개인정보

- 모든 터치 대상 최소 44×44px
- 라이트/다크 양쪽에서 WCAG AA 대비 목표
- 파스텔 오행 글자와 해당 표면의 대비도 일반 텍스트는 4.5:1, 큰 한자는 3:1 이상을 목표로 한다.
- focus-visible ring 제공
- 확대 금지 없음
- 모달 role, aria-modal, focus restore 유지
- Android `allowBackup=false` 유지
- 저장 명반은 외부 서버로 전송하지 않는 기존 로컬 저장 방식을 유지

## 9. 호환성과 범위

변경 대상:

- `app/www/index.html`
- `app/www/polish.css`
- `app/www/luxury.css`
- 필요한 경우 `app/www/nav.js`, `share.js`
- `app/web`의 동일 배포 파일
- 테스트와 캡처 기준

변경하지 않는 것:

- 사주 계산 로직
- 저장 데이터 형식
- 공유 카드의 계산 내용
- Android 패키지 ID와 서명 키
- 오행의 의미와 명리 데이터

## 10. 검증

- 라이트와 다크 각각 입력·원국·풀이·궁합·만세력·저장 화면 캡처
- 360, 390, 412, 768px UI 회귀
- 한자 정사각형의 폭/높이 오차 1px 이하
- 동일 행 박스의 높이 오차 1px 이하
- 주요 단일 라벨의 박스 중심과 글자 중심 편차 2px 이하
- 한자 중심 좌표의 열간 편차 2px 이하
- 가로 overflow 검사
- 색 대비와 focus-visible 확인
- 모달, Android 뒤로가기, 저장 toast, 달력 전환 재검증
- 원본과 웹 미러 일치
- 보호 APK/AAB 재빌드 및 APK v2/AAB 서명 확인
