# 전설 만세력 시작 화면 분리 설계

작성일: 2026-07-27

## 문제

별도 배포 주소와 계산 기능은 정상이나, 첫 화면이 기존 `취명선 만세력`의 입력 화면을 거의 그대로 사용한다. 사용자는 새 제품이 아니라 이전 만세력이 다시 열린 것으로 인식한다.

## 결정

`전설`을 앱의 기본 목적지로 바꾸고, 사주가 아직 없는 전설 화면을 독립적인 시작 화면으로 구성한다. 기존 입력기는 검증된 계산 흐름을 보존하기 위해 `내 사주` 목적지에 유지한다.

색상만 바꾸는 방식은 제품 구분이 약하고, 전체 입력·계산 UI 재작성은 검증된 천년 계산과 접근성을 위험하게 하므로 제외한다.

## 시작 화면

- 상단 표식: `취명선 전설의 만세력`, `三元九運`
- 중심 정보: 현재 연도의 삼원구운 원·운·기간·오행
- 시각 구조: 180년 대순환을 나타내는 원형 궤도와 현재 20년 운의 강조
- 시간층 안내: `180년`, `20년`, `10년`, `1년`, `1개월`, `1일`, `2시간`
- 기본 행동: `내 전설 열기`
- 보조 행동: `유명인으로 보기`
- 출처 안내: 삼원구운 결합 해석은 취명선 창작 규칙이며 명리 계산값과 구분

## 동작

- 최초 진입 시 `전설` 탭과 전설 하단 내비게이션을 선택 상태로 표시한다.
- `내 전설 열기`는 `내 사주` 입력 화면으로 이동하고 생년월일 입력란에 초점을 둔다.
- `유명인으로 보기`는 입력 화면으로 이동한 뒤 인물 검색 모달을 연다.
- 사주 계산 후에는 기존 여덟 겹 시간 흐름과 전설 해석을 그대로 렌더링한다.
- 브라우저 뒤로가기나 저장 데이터 구조는 변경하지 않는다.

## 시각 방향

- 기존 검은 입력 화면 대신 미색 종이, 먹색, 인장색을 사용하는 전설 전용 화면을 첫 인상으로 삼는다.
- 큰 명조 제목, 산수 배경, 원형 시간 궤도, 비대칭 정보 배치로 기존 `神` 로고 중심 화면과 구분한다.
- iPhone식 하단 내비게이션과 즉각적인 눌림 피드백은 유지한다.
- 장식 애니메이션은 진입 계층을 설명하는 데만 사용하고 `prefers-reduced-motion`에서 제거한다.

## 접근성

- 시작 화면은 하나의 제목과 명확한 설명을 가진다.
- 두 행동은 실제 `button`으로 제공하고 44px 이상의 터치 영역과 가시적 포커스를 유지한다.
- 원형 궤도 장식은 보조기술에서 숨기고 동일 정보를 텍스트로 제공한다.
- 360px, 200% 확대, 감소된 동작 환경에서 가로 넘침과 필수 행동 가림이 없어야 한다.

## 검증

- 서버 HTML과 실제 브라우저 첫 화면이 `전설` 목적지로 시작하는지 확인
- 현재 연도의 삼원구운 정보가 `LegendEra.getLegendEra()` 결과와 일치하는지 확인
- 두 시작 행동이 각각 입력 화면과 인물 검색 모달로 연결되는지 확인
- 기존 71개 핵심 테스트와 5개 화면 폭 회귀 테스트 유지
- 새·기존 배포 주소의 제목과 첫 화면이 시각적·구조적으로 다른지 확인
- 서비스워커 캐시 버전을 갱신해 기존 배포본이 즉시 교체되는지 확인
