# 취명선 전설의 만세력 설계 명세

작성일: 2026-07-27  
대상: 기존 `jansang18/sineum-manse`를 기반으로 한 별도 웹/PWA  
제품명: **취명선 전설의 만세력**  
배포 목표: `https://jansang18.github.io/legend-manse/`

## 1. 목표

기존 취명선 만세력의 원국, 대운, 세운, 월운, 일운, 궁합, 저장 기능을 보존하면서 삼원구운을 개인 명리 위에 겹쳐 읽는 새로운 전설형 만세력을 만든다.

사용자는 자신의 사주를 계산한 뒤 다음 흐름을 한 화면에서 탐색한다.

`180년 대순환 → 20년 원운 → 본명반 → 10년 대운 → 1년 세운 → 1개월 월운 → 1일 일운 → 2시간 시운`

핵심 경험은 숫자와 표만 보여주는 것이 아니라, 사용자가 현재 어떤 시대와 개인 운의 풍경 안에 서 있는지를 수묵화, 큰 한자, 짧은 서사로 이해하게 하는 것이다.

## 2. 제품 원칙

- 기존 자평명리 계산과 새 삼원구운 창작 해석을 내부 데이터와 화면에서 분리한다.
- 전통적으로 확인 가능한 계산값은 `명리 계산`으로, 새로 만든 결합 해석은 `취명선 전설 해석`으로 표시한다.
- 20년 원운을 사주의 10년 대운이라고 부르지 않는다.
- 결과의 원인을 사용자가 확인할 수 있도록 오행 관계와 적용 규칙을 함께 보여준다.
- 건강, 재정, 관계의 결과를 단정하지 않고 경향과 행동 제안으로 쓴다.
- 출생 정보와 저장 명반은 기존처럼 사용자 기기에만 저장한다.
- 기존 `sineum-manse` 저장소와 배포 주소는 변경하지 않는다.

## 3. 브랜드와 시각 방향

참고 영상의 시각 문법을 앱 인터페이스로 재해석한다.

### 3.1 핵심 이미지

- 따뜻한 미색 한지 바탕
- 먹의 농담으로 표현한 산, 물길, 구름, 숲
- 장면마다 중심이 되는 큰 한자 한 글자
- 가는 먹선과 여백으로 연결되는 시간 흐름
- 붉은 낙관 형태의 브랜드 표식
- 오행별로 한 가지 절제된 보조색 사용

영상 프레임을 복제하지 않고 같은 정서와 재료감을 가진 앱 전용 수묵 자산을 새로 제작한다.

### 3.2 색상

| 역할 | 색 |
| --- | --- |
| 한지 바탕 | `#F2ECDD` |
| 한지 밝은 면 | `#FAF7EE` |
| 진한 먹 | `#20231F` |
| 옅은 먹 | `#77786F` |
| 낙관 | `#9E3E32` |
| 목 | `#3E6B57` |
| 화 | `#A94732` |
| 토 | `#9A742F` |
| 금 | `#6D7372` |
| 수 | `#355D6B` |

오행색은 칩, 선택선, 큰 한자의 일부에만 쓰고 배경 전체를 오행색으로 칠하지 않는다.

### 3.3 타이포그래피

- 큰 한자: 명조 계열 CJK 서체, 화면당 한 글자 또는 한 간지
- 한글 제목: 굵고 단정한 고딕
- 설명: 읽기 쉬운 고딕, 15px 이상
- 인장과 계층 라벨: 작은 명조 또는 고딕
- 숫자와 연도: 고정폭 숫자 기능을 사용할 수 있는 서체

### 3.4 모션

- 첫 결과 진입: 안개가 걷히듯 320~500ms 페이드
- 시대 계층 이동: 산수 배경이 8~16px 천천히 이동
- 운 선택: 선택된 한자 주변에 먹이 번지는 180~240ms 효과
- 하위 운 확장: 위 계층의 먹선이 아래 계층으로 이어지는 전환
- 모션은 `opacity`와 `transform` 중심으로 구현한다.
- `prefers-reduced-motion`에서는 위치 이동을 제거하고 짧은 교차 페이드만 사용한다.

## 4. 정보 구조

기존 기능을 다음 여섯 영역으로 정리한다.

1. `입력`: 이름, 성별, 양력/음력, 생년월일, 출생 시각
2. `명반`: 사주 원국, 십신, 지장간, 오행, 합충형파해, 신살
3. `전설`: 삼원구운과 개인 운을 결합한 핵심 서사
4. `운력`: 대운, 세운, 월운, 일운, 시운 탐색
5. `궁합`: 기존 두 명반 비교 기능
6. `보관`: 저장 명반, 검색, 가져오기, 내보내기

모바일에서는 탭을 한 줄에 억지로 넣지 않는다. 주요 다섯 영역은 하단 탐색으로 제공하고 `궁합`과 앱 정보는 더보기 메뉴에서 접근할 수 있게 한다. 데스크톱에서는 여섯 영역을 모두 노출할 수 있다.

## 5. 삼원구운 계산

### 5.1 기준 주기

기준점은 1864년 1운 시작으로 한다. 모든 연도는 180년 주기로 정규화한다.

| 원 | 운 | 기준 기간 | 괘 | 오행 | 전설 키워드 |
| --- | --- | --- | --- | --- | --- |
| 상원 | 1운 | 1864~1883 | 감 | 수 | 심연, 지혜, 이동 |
| 상원 | 2운 | 1884~1903 | 곤 | 토 | 수용, 돌봄, 기반 |
| 상원 | 3운 | 1904~1923 | 진 | 목 | 발동, 개척, 천둥 |
| 중원 | 4운 | 1924~1943 | 손 | 목 | 확산, 교류, 바람 |
| 중원 | 5운 | 1944~1963 | 중궁 | 토 | 중심, 전환, 재편 |
| 중원 | 6운 | 1964~1983 | 건 | 금 | 권위, 질서, 하늘 |
| 하원 | 7운 | 1984~2003 | 태 | 금 | 표현, 교환, 기쁨 |
| 하원 | 8운 | 2004~2023 | 간 | 토 | 축적, 경계, 산 |
| 하원 | 9운 | 2024~2043 | 리 | 화 | 가시성, 문명, 빛 |

이 표는 계산 데이터이며, 건물 좌향이나 방위 계산은 사용하지 않는다.

### 5.2 계산 결과

`getLegendEra(year)`는 다음 값을 반환한다.

- 180년 대순환 번호와 시작/종료 연도
- 상원, 중원, 하원
- 1~9운
- 해당 운의 시작/종료 연도
- 괘, 오행, 상징, 핵심 문장
- 운 진행률

주기 경계는 연 단위로 계산한다. 사용자의 생일 전후를 기준으로 원운을 나누지 않는다.

## 6. 개인 공명 해석

삼원구운은 본명반을 대신하지 않고 시대 배경으로만 작동한다.

### 6.1 입력값

- 현재 원운의 오행
- 일간 오행
- 명식의 오행 분포
- 취명선 용신 후보
- 현재 10년 대운의 천간과 지지 오행
- 선택한 세운, 월운, 일운, 시운의 오행

### 6.2 공명 관계

원운 오행과 개인 오행 사이의 관계를 다음 다섯 가지로 설명한다.

- `동조`: 같은 오행이 시대와 개인에게 함께 강해짐
- `생조`: 시대가 개인에게 필요한 오행을 생함
- `표출`: 개인이 시대의 오행을 생하며 능력을 밖으로 드러냄
- `압력`: 시대가 일간이나 필요한 오행을 극함
- `제어`: 개인이 시대 오행을 극하며 책임과 소모가 함께 커짐

### 6.3 공명 지수

공명 지수는 0~100의 예측 확률이 아니라 규칙 기반 설명 지표다.

- 원운과 용신 후보 관계: 35점
- 원운과 일간 관계: 25점
- 원운 오행이 명식의 부족한 부분을 보완하는 정도: 20점
- 현재 대운과 원운의 관계: 15점
- 선택한 단기 운과 원운의 관계: 5점

화면은 총점뿐 아니라 다섯 항목의 근거 문장을 보여준다. 용신 계산이 간이 모드일 때는 `간이 용신 기준` 배지를 표시한다.

### 6.4 전설 서사

전설 서사는 고정 문장 조각과 계산 결과를 조합한다.

구조:

1. 시대 풍경
2. 개인이 서 있는 자리
3. 시대와 개인의 공명 또는 마찰
4. 살려야 할 능력
5. 경계해야 할 과잉
6. 이번 시기에 실행할 한 가지 행동

예시 형식:

> 불의 시대가 모든 것을 보이게 합니다. 당신의 물은 그 빛을 끄기보다 방향을 잡아주는 거울이 되어야 합니다.

문장은 의료, 법률, 투자 결과를 예언하지 않는다. 건강은 생활 리듬, 재물은 지출과 계획, 관계는 대화와 경계처럼 사용자가 실행할 수 있는 표현으로 쓴다.

## 7. 핵심 화면

### 7.1 입력 화면

- 기존 입력 필드와 순서를 유지한다.
- 상단에 수묵 산맥과 `傳說` 인장을 배치한다.
- 계산 버튼 문구는 `나의 운세 두루마리 펼치기`로 변경한다.
- 지원 범위와 시각 기준을 입력 카드 아래에 명시한다.

### 7.2 전설 표지

계산 직후 가장 먼저 보이는 장면이다.

- 큰 글자: 현재 원운의 괘 또는 사용자의 일간
- 제목: `빛의 시대에 선 ○○`
- 부제: 현재 9운과 개인 공명 관계
- 현재 원운 기간과 진행률
- `전설 읽기`와 `명반 보기` 두 가지 행동

### 7.3 시간 두루마리

가로 시간축이 아니라 위에서 아래로 이어지는 세로 서사로 구성한다.

- 180년 대순환: 가장 옅고 넓은 산맥
- 20년 원운: 태양, 달, 구름 등 시대 상징
- 본명반: 중심에 선 개인의 간지
- 10년 대운: 산길
- 세운: 길 위의 관문
- 월운: 계절과 물길
- 일운: 발밑의 징검돌
- 시운: 빛과 그림자의 짧은 변화

각 계층은 접고 펼칠 수 있으며, 선택값이 아래 계층 해석에 전달된다.

### 7.4 전설 상세

- `시대와 나`
- `일과 역할`
- `재물과 기반`
- `관계와 마음`
- `몸과 리듬`
- `이번 운의 한 수`

각 절은 큰 한자, 한 문장 요약, 계산 근거, 2~4문장의 서사로 구성한다.

### 7.5 전문가 상세

모든 전설 카드에는 `근거 보기`가 있다.

근거 화면은 다음을 보여준다.

- 사용한 원운과 오행
- 일간과 용신 후보
- 대운 및 선택된 단기 운
- 생극제화 관계
- 적용된 가중치
- `전통 명리 계산` 또는 `취명선 창작 규칙` 구분

## 8. 계산 정확성과 경계 규칙

기존 절기 계산의 율리우스일 좌표 혼용 가능성을 먼저 수정한다.

### 8.1 명시할 규칙

- 기본 시간대: `Asia/Seoul`
- 연주와 월주: 정확한 KST 절입 시각 기준
- 기본 일 경계: 자정
- 선택 가능한 일 경계: 자정, 자시, 야자시 분리
- 진태양시: 기본 끔, 향후 별도 옵션
- 음력 윤달: 명시적 입력
- 1900년 이전 음력 변환은 지원하지 않거나 검증된 외부 엔진으로 교체

### 8.2 검증

- 평상일 사주 사례
- 입춘 1분 전, 정각, 1분 후
- 매월 절입 1분 전, 정각, 1분 후
- 23:00, 00:00, 01:00 경계
- 윤년과 윤달
- 한국의 역사적 표준시 변경이 포함된 날짜
- 삼원구운의 각 20년 경계
- 180년 순환 전후

기대값은 같은 내부 함수에서 만들지 않고 KASI 자료 또는 별도의 검증된 한국 만세력 엔진과 비교한다.

현재 `index.html`에 집중된 계산과 화면 코드를 단계적으로 분리한다.

브라우저에서 빌드 과정 없이 실행되는 현재 정적 PWA 특성을 유지한다. 모듈은 ES modules로 로드하며 GitHub Pages의 하위 경로에서도 상대 경로로 동작해야 한다.

## 10. 데이터와 저장

- 기존 저장 명반 스키마를 읽을 수 있어야 한다.
- 전설 버전이 추가하는 필드는 버전이 있는 별도 객체에 저장한다.
- 계산 결과를 저장할 때 원운 해석 전체를 복제하지 않고 입력과 규칙 버전을 저장해 다시 계산한다.
- 내보내기 파일에는 `product`, `schemaVersion`, `ruleVersion`을 포함한다.
- 외부 서버로 출생 정보를 전송하지 않는다.

## 11. 접근성

- 모든 본문과 버튼은 WCAG AA 대비를 목표로 한다.
- 수묵 배경 위 텍스트는 불투명한 한지 면을 사용한다.
- 큰 한자는 장식일 때 보조기술에서 숨기고 의미가 있을 때 한글 설명을 제공한다.
- 모든 운 선택 요소는 키보드로 조작할 수 있어야 한다.
- 색만으로 오행이나 길흉을 구분하지 않는다.
- 200% 확대와 360px 너비에서 가로 넘침이 없어야 한다.
- 모션과 투명도 감소 설정을 지원한다.

## 12. 오류 처리

- 지원하지 않는 음력 연도는 계산하지 않고 정확한 지원 범위를 안내한다.
- 절기 데이터를 구할 수 없으면 임의의 간지로 대체하지 않는다.
- 시각 미상은 시주와 시운을 제외하고 다른 결과를 유지한다.
- 전설 해석 생성 실패 시 명반과 운력 계산은 계속 사용할 수 있어야 한다.
- 가져오기 데이터는 기존 보안 검증과 필드 길이 제한을 유지한다.

- 원본 저장소에는 전설 버전 코드를 푸시하지 않는다.
- 전설 저장소의 기본 브랜치는 `main`으로 한다.

### 13.2 GitHub Pages

- 배포 소스: `main` 브랜치의 저장소 루트
- 목표 주소: `https://jansang18.github.io/legend-manse/`
- PWA scope와 start URL은 `/legend-manse/`에 맞춘다.
- 서비스 워커 캐시 이름은 기존 앱과 충돌하지 않는 `legend-manse-*`를 사용한다.
- manifest 이름과 앱 제목은 모두 `취명선 전설의 만세력`으로 통일한다.

### 13.3 원본 보호

- `https://jansang18.github.io/sineum-manse/`는 그대로 유지한다.
- 저장소, Pages 설정, 서비스 워커, 로컬 저장 키를 전설 버전과 분리한다.
- 전설 버전 장애가 기존 만세력 배포에 영향을 주지 않아야 한다.

## 14. 테스트와 출시 기준

### 계산

- 삼원구운 경계 테스트가 모두 통과한다.
- 절기 경계 테스트가 각 기둥별로 기대 결과와 일치한다.
- 기존 일반 사주 사례가 회귀하지 않는다.
- 공명 지수의 각 항목 합과 설명 근거가 일치한다.

### 인터페이스

- 360, 390, 412, 768, 1024px에서 주요 화면을 검사한다.
- 모든 하위 운을 선택하고 되돌아갈 수 있다.
- 긴 이름, 시각 미상, 지원 범위 오류가 레이아웃을 깨뜨리지 않는다.
- 명반 저장, 불러오기, 내보내기, 공유가 유지된다.
- 키보드 탐색, 포커스 복원, 모션 감소 모드가 동작한다.

### 배포

- 새 GitHub Pages 주소가 HTTPS로 열린다.
- 새 PWA를 설치할 수 있다.
- 오프라인 재방문이 가능하다.
- 기존 만세력 주소와 저장 데이터에 변화가 없다.
