# 팔품 운세 설계

- 작성일: 2026-07-27
- 제품: 취명선 전설의 만세력
- 기능명: 팔품 운세
- 표시 문구: `팔품 운세 · 취명선 창작 해석`
- 상태: 구현 전 설계 승인 대기

## 1. 목표

현재의 일반적인 사주 원국과 점수 중심 운세에서 벗어나, 태어난 절기 구간인 팔품을 개인 해석의 중심축으로 삼는다. 삼원구운은 시대의 큰 배경으로, 대운·세운·월운은 팔품의 역할이 언제 어떤 방식으로 드러나는지를 설명하는 시간축으로 사용한다.

사용자는 앱에 들어오자마자 사주 입력 화면을 보고, 입력 후 별도 탐색 없이 올해의 팔품 운세를 읽을 수 있어야 한다. 다음 달, 월별, 내년 운세도 같은 화면에서 즉시 전환할 수 있어야 한다.

## 2. 비목표

- 특정 강의자의 공식 앱이나 공식 해석이라고 주장하지 않는다.
- 공개 영상의 문장이나 유료 강의 내용을 복제하지 않는다.
- 팔품만으로 길흉을 단정하거나 미래 사건을 확정하지 않는다.
- 삼원구운을 개인 사주의 모든 결과를 결정하는 단일 점수로 만들지 않는다.
- 기존 원국, 대운, 세운, 만세력 기능을 제거하지 않는다.

## 3. 명칭과 출처 경계

화면의 기능명은 중립적인 `팔품 운세`로 한다. 부제와 결과 하단에는 `취명선 창작 해석`을 표시한다.

도움말에는 다음 취지의 출처 설명을 둔다.

> 팔품은 사계절의 기운과 형상을 여덟 절기 구간으로 나누어 보는 공개 명리 개념을 참고했습니다. 이 앱의 조합 규칙, 문장, 점수와 조언은 취명선 전설의 만세력을 위한 창작 해석이며 특정 학파나 강의자의 공식 판정이 아닙니다.

참고한 공개 1차 자료:

- 더큼학당, `[자평명리학] 팔품(八稟) 명리학의 첫 걸음`
- 더큼학당, `용신과 희기신으로 운세보는법 | 창광 운세추명법 8`
- 더큼학당, `팔품, 격국이 끝이 아니다`
- 더큼학당, 2026 팔품 운세 공개 시리즈

링크는 앱의 `해석 기준과 출처` 펼침 영역에 제공하되, 결과 본문을 방해하지 않도록 한다.

## 4. 팔품 분류

출생지의 표준시를 기준으로 출생 순간이 어느 절기 경계 사이에 있는지 판정한다. 경계는 날짜가 아니라 절입 시각을 사용한다.

| 팔품 | 시작 포함 | 종료 제외 | 당령 |
| --- | --- | --- | --- |
| 자축품 | 동지 | 입춘 | 계수 |
| 인묘품 | 입춘 | 춘분 | 갑목 |
| 묘진품 | 춘분 | 입하 | 을목 |
| 사오품 | 입하 | 하지 | 병화 |
| 오미품 | 하지 | 입추 | 정화 |
| 신유품 | 입추 | 추분 | 경금 |
| 유술품 | 추분 | 입동 | 신금 |
| 해자품 | 입동 | 동지 | 임수 |

경계 시각과 정확히 같은 순간은 새 팔품의 시작으로 처리한다. 예를 들어 입춘 시각과 같으면 인묘품이다.

### 역사 범위

- 1800년 이후: 현재 정밀 절기 엔진의 절입 시각을 사용한다.
- 1026~1799년: 기존 역사 달력의 근사 절기 계산을 사용하고 결과에 `역사 범위 근사` 배지를 표시한다.
- 출생 시각을 모르는 사용자가 절기 경계일에 태어난 경우: 한쪽을 임의 선택하지 않고 `팔품 경계 가능성`을 표시하며 두 후보의 공통점과 차이를 함께 보여준다.
- 1908년 이전 민간시와 시간대의 불확실성은 기존 계산 안내를 유지한다.

## 5. 해석 구조

해석은 세 층을 순서대로 합성한다.

### 5.1 팔품: 개인의 계절적 역할

팔품은 사용자가 태어난 계절의 과제와 사회적 역할을 설명하는 첫 번째 축이다.

각 팔품 데이터는 다음 필드를 가진다.

- 계절의 장면
- 당령과 핵심 작용
- 잘 드러나는 역할
- 기회가 열리는 방식
- 과해질 때의 부담
- 준비하면 좋은 태도
- 관계, 일, 재물, 건강 관리의 관찰점

당령이 원국 천간·지지와 지장간에 얼마나 드러나는지에 따라 `발현`, `보완`, `전환`, `축적` 중 하나의 상태를 선택한다. 이 상태명은 취명선의 창작 모델이며 전통 격국의 확정 판정으로 표시하지 않는다.

### 5.2 삼원구운: 시대의 배경

삼원구운은 개인 적합도를 직접 결정하지 않고, 팔품의 역할이 놓인 사회적 환경을 설명한다.

현재 9운의 경우 화·빛·가시성·속도·표현이라는 배경 키워드를 사용하되, 개인 원국과 팔품에 따라 다음처럼 다르게 서술한다.

- 순행: 시대가 팔품의 역할을 쉽게 드러내는 경우
- 증폭: 기회와 부담이 함께 커지는 경우
- 조율: 속도나 방향을 조절해야 하는 경우
- 축적: 외부 노출보다 기반을 만드는 경우

삼원구운의 영향은 결과 전체의 보조 근거로 사용한다. 단독으로 좋음·나쁨을 판정하거나 총점의 과반을 차지하지 않는다.

### 5.3 대운·세운·월운: 발현 시점

- 대운: 팔품의 역할이 장기간 어떤 환경에서 성장하거나 수정되는지 설명한다.
- 세운: 올해 또는 선택한 연도에 어떤 과제가 전면에 나오는지 설명한다.
- 월운: 해당 연도 안에서 실제 행동을 시작, 조정, 마무리할 시기를 설명한다.

합성 우선순위는 `팔품 → 대운 → 세운 → 월운 → 삼원구운 배경`으로 한다. 기존 십신·오행 점수는 근거 자료로 남기되 결과의 첫 문장이나 대표 제목으로 사용하지 않는다.

## 6. 창작 판정 규칙

### 6.1 입력 데이터

- 출생 연월일시, 성별, 양력·음력
- 사주 원국과 지장간
- 현재 대운
- 선택한 연도와 월의 간지
- 해당 연도의 삼원구운
- 출생 절기와 팔품

### 6.2 결과 상태

대표 결과는 100점 단일 숫자보다 다음 네 상태를 우선 표시한다.

- 발현: 원래 역할을 드러내기 좋은 시기
- 전환: 기존 방식을 바꾸거나 역할을 이동할 시기
- 조율: 관계, 속도, 자원 배분을 정리할 시기
- 축적: 실력, 기반, 회복을 우선할 시기

점수는 비교를 돕는 보조 지표로만 남길 수 있다. 모든 결과에는 왜 해당 상태가 나왔는지 최소 세 가지 근거를 표시한다.

예시 근거:

- `출생 팔품: 신유품, 당령 경금`
- `올해 세운이 당령의 작용을 밖으로 드러냄`
- `9운의 화 기운이 성과 노출을 높이지만 소모도 키움`

### 6.3 영역별 해석

각 기간 결과는 다음 순서로 제공한다.

1. 이번 시기의 한 문장
2. 팔품의 역할과 현재 상태
3. 기회
4. 부담과 주의
5. 준비할 일
6. 관계·직업·재물·건강 관리
7. 판정 근거

건강 영역은 생활 관리 참고로만 표현하고 질병 진단, 치료, 약물 중단을 제안하지 않는다. 재물 영역은 투자 수익이나 손실을 보장하지 않는다.

## 7. 화면 흐름

### 7.1 시작 화면

앱의 기본 진입 화면을 현재의 전설 메인 배너가 아니라 `사주 입력`으로 바꾼다.

- 상단 브랜드 헤더 유지
- 화면 상단 세그먼트: `사주 입력 · 원국 · 전설`
- `사주 입력` 기본 선택
- 현재 인장, 먹색, 한지 질감과 적갈색 포인트 유지
- 기존 인물 검색과 고급 계산 설정 유지
- 주 버튼 문구: `팔품 운세 펼치기`

저장된 명반이 있더라도 앱 첫 진입은 입력 화면으로 한다. 마지막 입력값은 복원할 수 있지만 자동 계산은 하지 않는다.

### 7.2 계산 후 이동

`팔품 운세 펼치기`를 누르면 다음 순서로 동작한다.

1. 입력 검증
2. 원국과 절기 계산
3. 팔품 판정
4. 결과 저장
5. `운의 흐름 > 팔품 운세`로 이동
6. 기본 기간 `올해의 운` 표시

### 7.3 팔품 운세 화면

상단에는 네 개의 빠른 기간을 둔다.

- 올해
- 다음 달
- 월별
- 내년

`월별`에서는 연도 이전·다음 이동과 12개월 선택을 모두 제공한다. 따라서 현재 7월만 보이는 구조를 없애고, 과거·미래 연월을 같은 화면에서 탐색할 수 있게 한다.

결과 첫 화면은 다음 카드로 구성한다.

- 팔품 인장과 이름
- 선택 기간의 대표 상태
- 한 문장 해석
- 기회·부담·준비 3열 요약
- 관계·직업·재물·건강 상세
- `왜 이렇게 보나요?` 근거 펼침
- `해석 기준과 출처` 펼침

### 7.4 기존 기능 위치

- `전설사주 > 원국`: 사주 네 기둥, 십신, 대운, 세운
- `운의 흐름 > 팔품 운세`: 올해, 다음 달, 월별, 내년
- `궁합`: 기존 기능 유지
- `만세력`: 달력 기능 유지
- `보관함`: 저장된 명반과 운세 진입

하단 내비게이션은 기존 다섯 항목을 유지하고 콘텐츠를 가리지 않도록 현재의 불투명 배경과 하단 여백을 유지한다.

## 8. 데이터와 호환성

팔품은 기존 저장 명반의 출생 데이터에서 파생 계산한다. 저장 데이터 스키마를 불필요하게 마이그레이션하지 않고, 필요하면 캐시 필드에 계산 버전만 추가한다.

권장 데이터 구조:

```js
{
  version: "palpum-v1",
  type: "신유품",
  ruler: "경금",
  boundaryAccuracy: "exact" | "historical-approximation" | "uncertain",
  state: "발현" | "전환" | "조율" | "축적",
  evidence: [],
  interpretation: {}
}
```

판정 규칙과 해석 문구는 계산 코드에서 분리된 데이터 모듈로 관리한다. 문구를 바꾸어도 절기 판정과 원국 계산이 변하지 않아야 한다.

## 9. 오류와 불확실성

- 필수 생년월일 오류: 입력칸 가까이에 구체적인 수정 안내를 표시한다.
- 출생 시각 미입력: 시주를 제외한 해석임을 명시한다.
- 절기 경계 불확실: 두 팔품 후보를 표시하고 시간 입력을 권한다.
- 역사 범위 근사: 결과 상단에 배지를 표시하고 정확도 설명을 제공한다.
- 계산 실패: 기존 입력을 보존하고 다시 시도할 수 있게 한다.
- 저장 데이터가 오래된 경우: 원본 출생값으로 재계산하며 사용자 기록을 삭제하지 않는다.

## 10. 검증

### 10.1 팔품 경계

각 연도의 동지, 입춘, 춘분, 입하, 하지, 입추, 추분, 입동에 대해 다음 세 시점을 검증한다.

- 경계 1분 전
- 경계 시각
- 경계 1분 후

경계 시각부터 새 팔품이 선택되어야 한다. 가능한 경우 기대값은 같은 계산 함수가 아니라 공인 역서 또는 독립된 절기 자료로 만든다.

### 10.2 시간 기준

테스트와 화면 도움말에 다음 가정을 명시한다.

- 기본 시간대: Asia/Seoul
- 1908년 이후: 기존 KASI 기반 민간시 처리
- 1800~1908년: 기존 UTC+9 근사
- 1026~1799년: 기존 역사 범위 근사
- 일주 경계와 야자시 처리: 기존 만세력 설정을 그대로 따른다.
- 진태양시: 사용자가 고급 설정에서 선택한 경우에만 적용한다.

### 10.3 회귀 테스트

- 기존 원국 네 기둥 결과가 바뀌지 않는다.
- 기존 저장 명반을 열 수 있다.
- 인물 검색 자동 입력이 유지된다.
- 올해에서 다음 달, 월별, 내년으로 이동해도 선택한 명반이 유지된다.
- 12월의 다음 달은 다음 해 1월로 이동한다.
- 연도 이동은 앱 지원 범위 1026~2099를 넘지 않는다.
- 모바일 하단 내비게이션이 결과 마지막 카드를 가리지 않는다.
- 입력 숫자와 결과 한자가 밝은 배경에서 충분한 대비로 보인다.

## 11. 접근성

- 상태는 색만으로 구분하지 않고 이름과 설명을 함께 표시한다.
- 본문과 핵심 한자는 밝은 한지 배경에서 진한 먹색을 사용한다.
- 터치 목표는 최소 44px로 한다.
- 기간 전환, 근거 펼침, 오류 메시지에 접근 가능한 이름을 제공한다.
- 애니메이션은 짧은 전환에만 쓰고 `prefers-reduced-motion`을 따른다.

## 12. 완료 조건

- 첫 접속 시 사주 입력 화면이 열린다.
- 입력 버튼이 `팔품 운세 펼치기`로 표시된다.
- 계산 후 올해의 팔품 운세가 바로 열린다.
- 올해, 다음 달, 월별, 내년을 모두 탐색할 수 있다.
- 팔품 8구간이 절입 시각 기준으로 판정된다.
- 결과가 팔품, 대운, 세운·월운, 삼원구운 근거를 구분해 보여준다.

- `취명선 창작 해석`과 출처 경계가 표시된다.
- 1026~1799년 결과에는 역사 범위 근사가 명시된다.
- 기존 원국, 궁합, 만세력, 저장 기능의 회귀 테스트가 통과한다.
- 모바일과 데스크톱에서 주요 내용이 고정 내비게이션에 가리지 않는다.
