# 취명선 명리학당 홈페이지 목업 디자인

## 목표

취명선의 수묵 산수, 한지, 먹색, 낙관이라는 기존 정체성을 유지하면서 교육 콘텐츠와 기본 만세력을 한곳에서 경험하는 애니메이션 중심 홈페이지 목업을 만든다. 회원, 게시판 저장, 실제 결제는 이번 범위에서 구현하지 않고 향후 백엔드 연결이 가능한 화면 구조와 상호작용만 제공한다.

## 화면 기준

- 주 기준 화면은 1920x1080 Full HD다.
- 1440x900, 1366x768, 1280x720에서도 핵심 문구, CTA, 만세력 입력이 첫 화면에서 잘리지 않아야 한다.
- 태블릿은 768~1199px, 모바일은 360~767px로 재배치한다.
- 모바일에서는 장식 레이어 수와 패럴랙스 이동량을 줄이고 입력과 결과 접근을 우선한다.
- 모든 화면에서 가로 스크롤과 고정 메뉴에 의한 콘텐츠 가림이 없어야 한다.

3. 기본 만세력
4. 풀이 사례
5. 질문 게시판 목업
6. 강의 구매 목업

상단 고정 내비게이션은 위 영역의 앵커 이동을 제공한다. 기본 만세력 결과가 열린 뒤에도 내비게이션과 하단 CTA가 결과 내용을 가리지 않아야 한다.

## 홈 장면

첫 화면은 `취명선 명리학당` 제목과 현재 시대의 기운을 보여주는 9운 원형 장치를 중심으로 구성한다. 배경은 수묵 산수 이미지를 세 개의 깊이 레이어로 나누어 포인터와 스크롤에 미세하게 반응시킨다. 안개는 좌우로 천천히 흐르고, 제목은 먹이 번진 뒤 글자가 선명해지는 방식으로 등장한다. 낙관은 마지막에 짧은 압인 동작으로 찍힌다.

첫 화면의 주요 행동은 `명리 공부 시작하기`와 `내 사주 펼쳐보기` 두 가지로 제한한다. 사용자가 다음 장면을 쉽게 이해하도록 아래쪽에 움직이는 스크롤 안내를 둔다.

## 교육 콘텐츠 목업

교육 과정은 다음 네 묶음으로 보여준다.

- 명리의 기초
- 사주 원국 읽기
- 대운, 세운, 월운
- 삼원구운과 시대 해석

각 과정 카드는 난이도, 예상 학습 시간, 강의 수, 진행률 예시를 포함한다. 카드를 열면 강의 소개, 목차, 미리보기 영상 프레임, 수강 버튼이 있는 상세 패널이 나타난다. 실제 영상 재생과 수강 기록 저장은 목업 범위에서 제외한다.

## 기본 만세력

기본 입력은 이름, 성별, 양력/음력, 생년월일, 태어난 시간으로 제한한다. 기존 계산 엔진을 재사용하여 연주, 월주, 일주, 시주와 대운 흐름을 표시한다. 입력 오류와 시간 미상 상태를 명확히 안내한다.

결과는 교육 목적에 맞게 각 기둥을 눌렀을 때 천간, 지지, 오행, 십성에 대한 짧은 학습 설명이 펼쳐지는 구조로 만든다. 상세 운세 단정이나 결제 유도는 넣지 않는다.

## 게시판과 결제 목업

게시판은 질문 목록, 카테고리, 검색, 글쓰기 버튼, 글 상세 패널을 제공하되 새로고침 후 데이터가 유지되는 실제 작성 기능은 제공하지 않는다. 글쓰기 동작은 `목업 기능`임을 알리는 안내로 끝난다.

결제 영역은 강의 패키지, 가격 예시, 포함 콘텐츠, 구매 버튼을 보여준다. 구매 버튼을 누르면 결제 수단 선택 형태의 시각적 목업을 열고 실제 결제는 진행하지 않는다. 실제 결제처럼 오인되지 않도록 `현재는 시연 화면이며 결제가 발생하지 않습니다`를 표시한다.

## 모션 체계

- 첫 진입: 안개 흐름, 먹 번짐, 제목 분리 등장, 낙관 압인
- 포인터: 산수 레이어와 9운 원형의 미세한 깊이 반응
- 스크롤: 장면별 수묵 마스크 공개와 카드 순차 등장
- 9운 원형: 느린 회전과 현재 운 강조 맥동
- 교육 카드: 종이를 펼치는 높이와 그림자 변화
- 만세력: 네 기둥 순차 낙하, 오행 색의 짧은 번짐
- 모달: 한지가 펼쳐지는 스케일과 투명도 전환
- 숫자: 강의 수, 학습 시간, 진행률의 짧은 카운트업

지속 애니메이션은 배경 안개와 9운 원형만 허용한다. 사용자가 입력하거나 결과를 읽는 동안에는 장식 움직임을 약화한다. `prefers-reduced-motion`에서는 패럴랙스, 회전, 번짐을 제거하고 짧은 투명도 전환만 사용한다.

## 시각 언어

- 바탕: 따뜻한 백색 한지와 옅은 섬유 질감
- 글자: 먹색과 흐린 먹색
- 강조: 취명선 낙관의 적갈색
- 보조: 오행색은 작은 표식과 결과 카드에서만 절제해 사용
- 형태: 둥근 앱 카드보다 족자, 화선지, 목판 인쇄의 모서리와 여백을 우선
- 타이포그래피: 제목은 명조 계열, 본문은 가독성 높은 고딕 계열

## 기술 구조

- 기존 정적 웹앱과 계산 엔진을 재사용한다.
- 홈페이지 렌더링, 모션 제어, 만세력 학습 패널을 각각 독립 모듈로 분리한다.
- CSS 애니메이션은 단순 반복과 진입 효과를 담당한다.
- 포인터 패럴랙스와 스크롤 장면 전환은 `requestAnimationFrame` 기반의 작은 컨트롤러가 담당한다.
- 실제 게시판, 회원, 결제 API는 호출하지 않는다.
- 서비스워커 캐시 이름을 새 릴리스 버전으로 올려 기존 사용자가 최신 디자인을 받게 한다.

## 오류 및 접근성

- 만세력 계산 실패 시 입력 영역 가까이에 원인과 수정 방법을 표시한다.
- 버튼, 카드, 모달은 키보드로 사용할 수 있어야 한다.
- 모달은 초점 가두기, ESC 닫기, 닫힌 뒤 원래 버튼으로 초점 복귀를 지원한다.
- 텍스트 대비는 WCAG AA를 목표로 한다.
- 장식 요소는 스크린리더에서 숨기고 핵심 이미지는 대체 설명을 제공한다.

## 검증 기준

- 1920x1080에서 첫 화면이 하나의 완성된 장면으로 보인다.
- 1280x720에서 제목, 설명, 두 CTA가 잘리지 않는다.
- 360x800에서 가로 스크롤이 없고 기본 만세력 입력이 한 열로 표시된다.
- 모든 애니메이션은 모션 축소 설정에서 중지되거나 단순화된다.
- 기본 만세력 계산의 기존 핵심 테스트가 모두 통과한다.
- 고정 내비게이션과 CTA가 명식 및 대운 결과를 가리지 않는다.
- 콘솔 오류, 누락 자산, 깨진 링크가 없다.

## 범위 제외

- 실제 회원가입과 로그인
- 서버 저장 게시판
- 실제 결제 및 환불
- 관리자 페이지
- 실제 영상 스트리밍과 수강 진도 저장
